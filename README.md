# Atelier — 示範落地頁

靜態單頁網站，可透過 [GitHub Pages](https://pages.github.com/) 託管。

## 本機預覽

在專案目錄執行任意靜態伺服器，例如：

```bash
python3 -m http.server 8080
```

然後開啟 `http://localhost:8080`。

## 自訂

- 將 `index.html` 內 `hello@example.com` 改為你的聯絡信箱。
- 可依需求替換 Unsplash 圖片連結（請保留授權與來源說明）。
